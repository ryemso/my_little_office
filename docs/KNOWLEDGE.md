# 대표 지식과 업무 자료 (v0.9)

기존 앱을 종료하고 `update-office.bat`을 실행합니다. 회사 지식실에서 대표의 경험·기술·업무 방식을 입력하고 저장하세요. 별도로 제공된 초기 프로필 JSON은 **대표 초기프로필 가져오기 → 대표 프로필 저장**으로 한 번 가져옵니다. 프로필은 로컬 DB에 저장합니다. ChatGPT의 과거 대화나 계정 메모리를 자동으로 읽지 않습니다. 초기 경험은 직원이 새로운 기술을 학습하는 데 제한을 두지 않습니다.

공통 자료는 매 업무에 자동 포함하며 업무 화면에서 해당 업무만의 파일과 링크를 추가할 수 있습니다. 이전 자료도 선택할 수 있습니다. 지시문 안의 공개 링크도 최대 5개 읽습니다. 같은 화면에서 같은 링크를 재사용하면 처음 읽은 자료를 재사용합니다. 갱신이 필요하면 공통 자료 링크 등록으로 다시 읽으세요. 등록된 자료는 읽음·읽기 실패 및 이유·미리보기를 표시합니다. 링크 수집은 Python 서버에서 실행하며 모델이 읽었다고 추측해 표시하지 않습니다.

## 지원 범위

- 파일당 최대 10MB. 텍스트·코드·Markdown·CSV·JSON·노트북·PDF·DOCX·XLSX·ZIP·PNG/JPG/WEBP.
- PDF 앞 100페이지 텍스트 추출. 스캔 PDF 자동 OCR은 없으므로 OCR한 PDF 또는 이미지로 올립니다. 암호화 문서는 해제해야 합니다.
- XLSX 미리보기 최대 10시트·200행·30열, ZIP은 텍스트 최대 30개 미리보기. 원본은 직원에게 경로로 제공합니다. ZIP은 자동으로 풀거나 실행하지 않습니다.
- 이미지 직접 입력은 업무당 앞 5개입니다. 추가 이미지는 원본 경로만 제공합니다. 이미지가 많으면 업무를 나누세요.
- 공개 HTTP/HTTPS 문서와 GitHub README·파일 링크를 읽습니다. 로그인·브라우저 쿠키·JavaScript 실행이 필요한 페이지는 지원하지 않습니다. 권한 있는 자료를 파일로 올리세요.
- 사설망·localhost·클라우드 메타데이터 주소는 수집하지 않습니다. DNS 확인 후 공개 IP에 연결하고 리디렉션마다 재확인합니다. 수집 시간·크기·횟수 제한이 있습니다.

## 직원에게 전달하는 방법

접수 당시 대표 프로필·자료 ID·출처·상태·관련 발췌문을 업무에 고정합니다. 선택 자료를 우선하며 총 20개, 본문 발췌 합계 24,000자 한도로 관련 키워드가 있는 부분을 우선합니다. 많은 자료는 나누어 지시하세요. 이는 키워드 기반 참고 자료 검색이며 모델 재학습은 아닙니다. 전체 원본은 해시를 검증한 뒤 읽기 자료 경로로 복사합니다. 직원과 총괄 최종 보고는 같은 접수 자료를 이어받습니다. 기존 접수 업무는 프로필을 고쳐도 바뀌지 않으므로 새 업무를 지시합니다.

원본은 로컬 상태 폴더의 `knowledge/files`에 보관하고 작업별 `inputs`로 전달합니다. 프로젝트의 `work` 폴더·변경 ZIP·자동 공개 코드에는 넣지 않습니다. 업무 실행 시 프로필과 발췌문·이미지는 Codex에 전달됩니다. 생성 결과가 입력 정보를 인용할 수 있으므로 외부 게시 전 결과를 확인하세요. 회사 지식실 자체는 공개 Pages가 아닌 PC 실행 앱에 있습니다. 자료 본문에 포함된 명령으로 직원의 실행 권한이 변경되지는 않습니다.

검증은 프로필 고정·직원/보고 상속, 원본 무결성·이미지 전달 준비, 자료 우선순위·프로젝트 구분, 읽기 실패 표시, 문서 추출·공개 주소 검사와 기존 UI/실행 회귀를 포함합니다. 실제 Windows PC의 Codex 로그인·이미지 모델 실행과 사이트별 네트워크 접근은 사용자 환경에서 최종 확인해야 합니다.
