사용자 지정 저장소 ryemso/my_little_office에 설계·코드·작업 경과를 저장한다. 사무실 접근은 GitHub Pages를 사용한다.
공개 저장소에는 민감정보를 제외한 기록만 남긴다.
## D004 — 화면과 실행 분리
초기 화면은 설계 탐색용이며 가짜 실행·매출을 표시하지 않는다. 실제 실행은 이후 서버 연결 범위다.
## D005 — 설계 진행
별도 수정 지시가 없으면 설계를 순차 진행한다. 비용·계정·민감한 권한 변경은 해당 정책에 따라 확인한다.
