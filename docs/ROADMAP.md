## 2026-10-21 — v0.9 대표 지식 기반·파일·공개 링크

대표 프로필·공통 자료·업무 첨부와 공개 URL 읽기를 추가했습니다. 프로필과 출처를 접수 시점에 고정해 총괄·직원·최종 보고에 전달하고, 원본은 작업 사본 밖의 읽기 자료로 제공합니다. 공개 동기화 필드에는 지식 원문을 추가하지 않습니다. URL은 공개 IP만 연결하고 리디렉션마다 검증하며 로그인·JavaScript를 실행하지 않습니다. 실패는 자료 상태와 이유로 표시합니다. 모델 재학습이나 ChatGPT 대화 자동 연동은 아닙니다. 상세는 [KNOWLEDGE.md](KNOWLEDGE.md). 개인 초기 프로필은 공개 저장소에 넣지 않고 별도 가져오기 파일로 제공합니다.

## 2026-10-21 — v0.8 실제 실행 작업공간·서비스 연결

초안 전용 제한을 제거하고 회사 작업실·등록 프로젝트의 사본에서 실제 파일 작성·수정·테스트·빌드·분석을 수행하도록 확장했습니다. 총괄과 직원은 프로젝트를 공유하고 변경 파일·명령·종료 코드를 기록합니다. 원본 반영은 기존 변경 충돌 검사와 백업을 거칩니다.

배포·홍보·기타 서비스 작업은 소유자가 등록한 명령·대상·자동 실행 권한을 사용합니다. 미승인 연결은 구체적인 결과 확인 뒤 승인하고, 미등록 작업은 실행하지 않습니다. 모든 플랫폼 전용 커넥터를 내장한 상태는 아니며 실제 CLI·스크립트·계정 연결이 필요합니다. 자세한 사용·설계·검증은 [EXECUTION.md](EXECUTION.md)를 따릅니다. 44개 테스트를 통과했으며 실제 Codex 구독과 외부 서비스 계정 실행은 PC에서 최종 확인해야 합니다. 아래는 이전 기록입니다.

## 2026-10-21 — v0.7 총괄 자동 배정·업데이트 후 실행

대표의 지시를 총괄이 최대 6개 직원 업무로 배정하고, 결과를 순차 전달한 뒤 최종 보고하는 DB 기반 실행을 구현했습니다. 계획 검증·종속 업무 중단·중복 방지·재시작 복구·기존 DB 이전을 적용했습니다. 작업 범위는 문서·코드 초안이며 실제 프로젝트 파일 수정은 후속 단계입니다.

ZIP 설치 이후 update-office.bat으로 최신 코드를 받아 실행하도록 구현했습니다. 배포 목록·해시 검증, 사용자 수정 감지, 가상환경·업무 DB 보존, 실행 잠금, 백업·실패 및 중단 복구를 추가했습니다. 사용법과 설계는 [DELEGATION_AND_UPDATES.md](DELEGATION_AND_UPDATES.md)를 따릅니다. 36개 모의·UI·업데이트 테스트를 통과했으며 실제 Codex 구독 실행과 Windows 환경의 최종 검증은 사용자 PC에서 진행해야 합니다. 아래는 이전 기록입니다.

## 2026-10-21 — 일일 근무 제한 폐지

사용자 요청으로 5시간 × 2회 제한을 제거했습니다. 출근 후 직접 퇴근·PC 종료·실행 오류·Codex 한도 대기 전까지 업무를 처리하며 자정에 종료하지 않습니다. 오늘 근무 구간·남은 시간 UI를 제거하고 실행 대기 수를 표시합니다. 기존 DB의 근무 구간과 만료된 종료 시각은 제한으로 적용하지 않습니다. Streamlit과 이전 CLI 실행기 모두 변경했습니다. 개별 작업 20분 제한은 유지합니다. 회귀·UI 테스트를 포함한 21개 테스트로 확인했습니다. 아래의 시간 구간 관련 내용은 과거 기록입니다.
