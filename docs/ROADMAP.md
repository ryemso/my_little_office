## v0.6 구현 현황

완료: Streamlit 사무실 직접 지시, 픽셀 아바타 선택, 로컬 Codex 초안 어댑터, SQLite 큐·복구, 출퇴근·취소·한도 대기, 결과·검토·후속 지시, 공개 기록 동기화, Windows 설치·실행 스크립트. Pages에서 로컬 앱을 여는 흐름으로 복사·외부 재입력을 제거했습니다.

다음 검증: 사용자 PC에서 Codex ChatGPT 로그인과 실제 업무 1건, Windows 실제 브라우저·프로세스 중단 확인. 다음 기능: 허용 프로젝트 등록 → 격리 작업공간 파일 수정·테스트 → 직원 간 업무 이어받기. Pages의 직접 로컬 API 연결과 모바일 원격 명령은 별도 단계입니다. 아래는 이전 계획 기록입니다.

## v0.5 현재 상태 (2026-10-21)

API 기반 Actions 실행을 로컬 Codex 출근 실행기로 교체했습니다. Actions는 공개 동의가 있는 업무를 대기열에 넣고, PC 실행기가 순차 처리해 검토용 초안을 저장합니다. 인증 정보는 PC에만 유지합니다. 한국 날짜 기준 5시간 구간 2회, 작업당 20분, 오류 시 중단, 체크포인트 복구를 적용했습니다. 실제 구독 로그인 실행은 사용자 PC에서 확인해야 합니다. 제품 작업공간 연결과 실시간 온라인 감지는 다음 단계입니다. 자세한 운영 방식은 [AI_SETUP.md](AI_SETUP.md)를 따릅니다. 아래 이전 기록의 API 설정은 과거 설계입니다.
