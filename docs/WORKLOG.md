## 2026-10-21 — v0.6 Streamlit 직접 업무 실행 구현

Reflex와 Streamlit의 공식 문서를 비교하고 PC 실행에 맞는 Streamlit을 채택했습니다. 기존 오리지널 픽셀 아바타를 양방향 컴포넌트로 재사용하고, 출퇴근·직원 선택·직접 명령·영구 대기열·Codex 초안·추가 지시·검토·중단·재시작 복구를 구현했습니다. Pages의 명령 복사 UI를 로컬 실행 사무실 입구로 교체했습니다. Windows 설치·실행 배치 파일과 선택적 공개 기록 동기화를 추가했습니다.

검증: Python 20개 테스트(백엔드, 모의 CLI 어댑터, Streamlit AppTest), 컴포넌트 연결·아바타 선택 Node 계약 검사, JS 문법·정적 링크·생성 자산 일치, 로컬 Streamlit health 및 HTML 응답 확인. 실제 Codex 호출은 하지 않았습니다. 사용자 PC의 구독 로그인·Windows 프로세스 중단·실제 브라우저 아바타 선택은 최종 확인이 필요합니다. 제품 파일 수정·테스트 실행은 다음 단계입니다.

# 작업 기록
## 2026-10-21 — 프로젝트 기반 구성
빈 공개 저장소를 확인하고 회사·직무·권한·데이터·결정·계획 문서를 작성했다.
클릭 가능한 정적 사무실과 Pages 워크플로를 구성했다.
실제 에이전트·매출·지출·외부 발송 기능은 연결하지 않았다.
검증은 파일·문서 연결과 정적 스크립트 문법을 기준으로 수행한다.
후속 작업은 변경 목적·파일·검증·남은 제약을 이 문서에 기록한다.

## 2026-10-21 — 공간형 사무실과 고유 아바타
사용자 제공 ZEP 참고 이미지의 공간 배치를 기준으로, 카드형 목록을 2D 사무실로 변경했다. 아바타와 가구는 원본 이미지에서 추출하지 않고 SVG/CSS로 작성했다. 직원별 머리·의상·피부색·안경을 구분하고 선택 프로필, 회의실 이동, 자리 복귀, 이동 시연 시작·중지를 추가했다. 실제 에이전트는 미연결이며 이동 시연을 업무 실행으로 표시하지 않는다. 후속 연결은 Run 상태에 따라 자리·이동·검토 상태를 표시하는 방식으로 진행한다.

## 2026-10-21 — 아바타 귀여운 스타일 보완
큰 머리·작은 몸의 둥근 비율, 눈 하이라이트·볼터치·미소를 추가했다. 대표 왕관·기획 리본·디자인 꽃핀과 직원별 머리·옷·안경으로 구분하며 이동·선택 기능을 유지했다. SVG/CSS 원본과 자산 버전을 갱신했다.

## 2026-10-21 — 레트로 2D 픽셀 사무실
사용자의 옛날 2D 오락게임 스타일 요청을 반영했다. 외부 ZEP·마리오 자산을 사용하지 않고 16×24 픽셀 문자 배열에서 SVG 스프라이트를 생성한다. 직원별 팔레트·왕관·리본·꽃핀·안경을 유지하며 앞·뒤·좌·우 방향과 이동 프레임을 표시한다. 가구·창문·식물·버튼도 각진 픽셀 스타일로 맞췄다. 실제 작업 서버는 여전히 미연결이고 이동은 명시적인 시연이다.

## 2026-10-21 — AI 업무 실행기 v0.4
GitHub 인증 후 수동 실행하는 직무별 AI 초안 워크플로, Responses API 호출기, 공개 업무 기록과 사무실 결과 표시를 추가했다. 공개 동의·API 키·모델이 없는 실행은 차단한다. 입력 5000자·출력 2400토큰·호출 1회·시간 제한을 적용했다. 결과는 검토 대기이며 코드·외부 도구를 실행하지 않는다. 4개 회귀 테스트와 정적 검사를 통과했다. API 키 미제공으로 실제 유료 호출은 수행하지 않았다.
