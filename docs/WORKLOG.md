## 2026-10-21 — Windows Codex 네이티브 실행

사용자 PC에서 오류 경로의 codex.exe 존재 및 직접 --version 실행(codex-cli 0.163.0)이 확인되었으나 Node 래퍼의 spawn은 ENOENT로 실패했습니다. .cmd 설치 발견 시 중첩·호이스팅·레거시 npm 구조에서 현재 아키텍처의 실재하는 네이티브 codex.exe를 우선 사용하도록 변경했습니다. 로그인 확인과 업무 실행에 같은 선택 경로를 사용합니다. 찾지 못하는 설치 구조는 기존 래퍼를 사용합니다. 한글 경로·x64·ARM64·래퍼 대체 테스트를 추가했습니다. 55개 테스트 통과. Windows 실제 업무 재실행 결과는 사용자 PC에서 확인해야 하며 ENOENT의 OS 수준 근본 원인은 단정하지 않습니다.

## 2026-10-21 — 로컬 실행 오류 진단 보완

로그인·파일·프로세스 예외를 동일한 일반 문구로 숨기던 오류 처리를 변경했습니다. 실제 예외 종류와 메시지 및 로컬 traceback 파일 경로를 표시하고, Codex가 stdin을 읽기 전에 종료한 경우 파이프 오류 대신 종료 코드와 stderr를 표시합니다. 일반적인 키·토큰은 진단에서 마스킹합니다. 오류 시 근무 중단은 유지하며 자동 재시도하지 않습니다. 두 재현 테스트를 추가해 총 53개 테스트를 통과했습니다. 이는 진단 경로 수정이며 사용자 PC의 원래 실패 원인은 새 진단으로 확인해야 합니다.
