# 대표 검토·승인함 (v0.12)

실행 터미널을 종료하고 `update-office.bat`으로 업데이트하세요. 처리할 사안이 생기면 **대표 아바타 위에 `!`와 건수**가 표시됩니다. 대표 캐릭터나 느낌표를 클릭하면 검토·승인 팝업이 열립니다. 같은 기능을 사무실 아래 **대표 검토·승인함** 버튼으로도 열 수 있습니다. 키보드로 대표 버튼에 이동해 Enter·Space로 열 수 있으며, 색 외에 느낌표·건수·접근성 이름으로 알립니다.

## 모이는 사안

- 검토: 대표에게 제출된 개별 업무 결과와 총괄 최종 보고. 팀 직원의 중간 제출물은 중복 알리지 않습니다.
- 승인: 자동 실행을 미리 허용하지 않은 등록 연결 작업. 앞 직원 업무가 끝나지 않았으면 승인 버튼은 대기 상태입니다.
- 문제 확인: 대표 업무의 실패·팀 중단·실행 중단·사용 한도 대기 보고. 확인 여부는 해당 버전에 저장합니다.

집계는 최근 100개 업무 보드의 표시 범위에 제한되지 않으며 모든 프로젝트의 미처리 사안을 기준으로 합니다. 사무실은 2초마다 건수를 갱신합니다. 팝업은 열거나 새로고침할 때 현재 목록을 읽으며 유형별 필터와 20개씩 더 보기를 제공합니다. 대기 건수 0이면 느낌표를 숨깁니다. 100개 이상은 아이콘에서 `99+`로 표시합니다.

## 팝업에서 처리

**검토 완료**는 해당 결과를 완료로 처리합니다. 원본 파일 반영·게시·배포를 실행하지 않습니다. 전체 결과를 다운로드하고 실행 증거를 펼쳐 볼 수 있습니다.

**이 내용으로 실행 승인**은 작업 이름·실제 대상·실행 인자·현재 작업 사본의 변경 내용을 확인한 후 해당 연결 작업만 실행 대기열로 보냅니다. 퇴근 상태라면 출근 후 실행합니다. 팝업을 처음 연 시점의 파일 지문과 업무 버전을 보관하므로 이후 파일이 바뀌면 승인 버튼을 막고 새 변경 내용을 확인하게 합니다. 클릭 시에도 다시 검사하며 실제 실행기는 승인 이후 파일 변경을 추가 검증합니다. 실행 거절은 해당 팀 업무를 중단하고 그 상태를 대화에 남깁니다.

**문제 확인했음**은 오류 알림을 확인 처리합니다. 실행 완료나 재시도를 의미하지 않습니다. 재시작 후에도 같은 버전의 확인 상태를 유지하고, 이후 업무 상태가 새로 바뀌면 다시 알립니다.

**대화에서 확인·추가 지시**는 해당 업무방으로 전환하고 담당 직원·프로젝트·이전 업무를 선택한 뒤 팝업을 닫습니다. 위 업무 입력란에서 수정 요구를 제출하거나 같은 방의 채팅 입력을 사용할 수 있습니다. 팝업을 단순히 닫아도 미처리 사안은 유지합니다.

확인·승인 처리는 기존 로컬 업무 DB와 대화 기록에 저장하며, 실시간 서버나 외부 메시지 발송을 추가하지 않습니다. 기존 상세 관리에서도 같은 작업을 처리할 수 있습니다.
