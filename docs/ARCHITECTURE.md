# 시스템 설계
## 현재
GitHub: 설계·코드·결정·비식별 작업 기록의 기준 저장소.
GitHub Actions: 정적 파일 검사·Pages 배포.
GitHub Pages: 회사와 직무를 살펴보는 공개 사무실 화면.
AI 초안은 GitHub 인증 후 Actions에서 수동 실행하고 공개 JSON으로 기록한다. API 키와 모델 설정이 필요하다. 사무실 직접 실행 API·비공개 업무 DB·생성 코드 실행은 미연결이다. 상세: [AI 설정](AI_SETUP.md).

## 이후 연결
공개 화면 → 인증된 API → 권한 검사 → 업무 DB·대기열 → 실행기 → 결과물·검토.
작업 실행은 사용자 세션에 종속되지 않는 서버에서 처리한다. 브라우저에 비밀 키를 두지 않는다.
공개 소개와 실제 내부 업무를 분리한다. 내부 업무·승인·지출·고객 자료는 인증된 API로 제한하고 공개 JSON에 담지 않는다.

## 데이터 모델 초안
- Project: id, 목표, 범위, 자원, 예산, 검증·중단 기준
- Task: id, project_id, 목표, 입력, 담당, 검토자, 상태, 선행 작업, 완료 기준, 결과물 참조
- Run: id, task_id, 실행기, 시작·종료, 상태, 실제 비용, 마지막 신호
- Artifact: id, task_id, 저장 위치, 버전, 공개 범위, 검증 상태
- Approval: 대상 작업·버전, 구체 행동, 영향, 요청·결정 시각, 결정자, 만료
- Decision: 선택, 근거, 대안, 변경 이유
- Metric: 지표 정의, 기간, 원천, 측정값, 데이터 품질
실행 로그·거래 증거를 공개 저장소에 원문 저장하지 않는다.
